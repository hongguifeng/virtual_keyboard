## 阻断决定

当前构建只能作为未签名内部工程验证包，不能标记为 MVP 1.0 候选版。发布批准至少需要：

1. 修复 `REL-001`，把自动焦点观察、分类、目标会话、定位和 Overlay 状态接入 App 宿主。
2. 修复或正式变更 `REL-006` 的磁盘诊断/导出范围。
3. 在要求的 Windows/应用/DPI/多屏环境完成 T8.1/T8.2 和全部 AC 真人证据。
4. 补齐或正式接受 M7 被跳过造成的可靠性、安全、隐私和性能风险。
5. 对最终哈希制品完成有效恶意软件扫描；签名不可用时仅可批准明确范围的内部测试发布。

修复后必须生成新制品和新哈希，重新运行完整门禁并创建新的发布评审记录；本评审记录不可覆盖。
