# ADR-007：MVP 使用框架依赖便携 ZIP

- 状态：已采用
- 日期：2026-09-06
- 对应：T8.4

## 决策

MVP 1.0 首发 `win-x64` 框架依赖便携 ZIP。运行机器必须预先安装 .NET 10 Desktop Runtime x64。构建同时生成 ZIP 的 SHA-256 校验文件。

## 原因

- 当前项目尚无企业安装、签名证书或 MSIX 身份需求；便携包不引入新的安装器工具链和供应链依赖。
- 框架依赖包体较小，现有构建入口已经验证该发布模式。
- 应用所有运行时可写数据均位于 `%LocalAppData%\\VirtualKeyboard`，发布目录保持只读语义。

## 升级、卸载与回滚

- 升级：退出应用后，用新 ZIP 内容替换程序目录；不删除 `%LocalAppData%\\VirtualKeyboard`。
- 卸载：退出应用并删除程序目录。用户配置、布局、恢复文件和诊断数据默认保留；用户确认后可单独删除 LocalAppData 目录。
- 回滚：保留上一版本 ZIP，退出应用后替换程序目录。schema v1 配置继续复用；未来 schema 变更必须提供向后兼容或迁移策略。

## 后果

- 不是单文件、自包含或 MSI 安装包。
- 未安装正确 Desktop Runtime 时应用无法启动，用户文档必须给出明确前置条件。
- 该选择不等于发布批准；签名、恶意软件扫描和兼容验收仍由 T8.5/T8.7 门禁决定。
