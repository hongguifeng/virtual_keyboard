# ADR-002：自动隐藏遵循键盘焦点，不使用全局低级鼠标钩子

状态：已采用（Accepted）

日期：2026-09-06

关联：方案设计文档 ADR-002、§9；规格 §4、FR-VIS-002、AC-003；T0.1

## 背景

自动隐藏键盘需要在“用户离开输入状态”时触发。UI Automation 的 FocusChanged 事件可以检测焦点切换到非可编辑元素、其他应用或目标销毁，但无法证明每一次“点击窗口空白区域”的意图。候选方案之一是安装全局低级鼠标钩子（WH_MOUSE_LL）来推断点击意图。

## 决策

- 自动隐藏以“焦点是否仍在可编辑目标”为准，事件来源为 UIA FocusChanged，辅以前台窗口与焦点 HWND 校验。
- 当输入焦点仍停留在原可编辑目标时，即使发生不改变焦点的点击，MVP **不强制隐藏**键盘；该行为是明确产品语义（AC-003），不判定为缺陷。
- MVP **不安装**全局低级鼠标钩子来推断点击意图。
- 触发隐藏的条件限定为：焦点切换到 NotEditable 元素、前台应用切换且新应用无有效 Editable 目标、目标窗口/元素被销毁、程序被暂停。

## 后果

- 优点：避免全局钩子带来的权限、性能和误判风险；隐藏语义可判定、可测试（T2.5/T2.6 状态机与防抖）。
- 约束：用户点击空白区域时键盘保持可见，属设计内行为，需在用户文档中说明（T8.6）；如未来需要点击意图感知，须作为新 ADR 单独评审。
